## 继续制作

- 当前统一画风：有中国校园年代生活质感的二维青春动画。主线时间为 2005—2006 年，中学回忆为更早时期。
- 先读本目录索引及对应人物 README，再传入已采用的图片制作镜头。各目录保留现有提示词。
- 单幅图是用户确认的外观基准，多角度稿是据此补全的镜头参考，不能替代逐镜一致性检查。
- 侧面、背面、鞋型等新补全细节以配套图为参考；如与单幅冲突，优先保持已采用的五官、发型与气质。
