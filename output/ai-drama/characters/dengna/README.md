## 使用约定

基础多角度稿去掉 MP3、耳机线、笔记和荧光笔，展示身体与服装；道具在相应镜头参考单幅图另加。单幅未露出的鞋子补为朴素米白低帮帆布鞋。具体身高尚未确定，多人同框另统一比例。脸型、五官、丸子头、浓密齐刘海以已确认单幅为准，新增侧面、背面结构仍需逐镜核对。

v1 单幅为历史初稿，不作为当前生成基准。后续修改新建版本。
