# 徐皙 · 角色视觉资料

本目录仅保留用户采用的单幅形象及据此制作的配套多角度稿。
单幅形象为首要外观基准；多角度稿用于镜头参考，新增侧面、背面和未露出的服装结构仍需逐镜复核。

## 大学版本

- 单幅形象：[xuxi-look-v3.png](xuxi-look-v3.png)（用户已采用）。
- 多角度参考：[xuxi-turnaround-v1.png](xuxi-turnaround-v1.png)（四个全身角度、三个头部角度）。
- 特征：高马尾、轻薄刘海、较窄鹅蛋脸、圣诞老人发卡；浅蓝外套、白色内搭、黑色牛仔裤、白袜和黑色皮鞋。

- 提示词：[xuxi-look-v3-prompt.txt](xuxi-look-v3-prompt.txt)。
- 提示词：[xuxi-turnaround-v1-prompt.txt](xuxi-turnaround-v1-prompt.txt)。

## 后续使用

生成镜头时实际传入相应参考图，选择最接近目标镜头的角度；特写检查五官，全景检查身形与服装。表情、动作、俯仰角按分镜需要增补。多人同框时另行统一相对身高。
后续修改新建版本，不覆盖已采用图。原始真人照片不在本目录。
