# 吴彬 · 角色视觉资料

本目录仅保留用户采用的单幅形象及据此制作的配套多角度稿。
单幅形象为首要外观基准；多角度稿用于镜头参考，新增侧面、背面和未露出的服装结构仍需逐镜复核。

## 成年版本

- 单幅形象：[wubin-look-v2.png](wubin-look-v2.png)（用户已采用）。
- 多角度参考：[wubin-turnaround-v1.png](wubin-turnaround-v1.png)（四个全身角度、三个头部角度）。
- 特征：偏矮、五短身材、圆软肉脸、自然微扬嘴角、黑框眼镜；白衬衫、灰针织背心、黑外套。

- 提示词：[wubin-look-v2-prompt.txt](wubin-look-v2-prompt.txt)。
- 提示词：[wubin-turnaround-v1-prompt.txt](wubin-turnaround-v1-prompt.txt)。

## 后续使用

生成镜头时实际传入相应参考图，选择最接近目标镜头的角度；特写检查五官，全景检查身形与服装。表情、动作、俯仰角按分镜需要增补。多人同框时另行统一相对身高。
后续修改新建版本，不覆盖已采用图。原始真人照片不在本目录。
