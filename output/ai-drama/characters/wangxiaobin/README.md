# 王晓斌 · 角色视觉资料

本目录仅保留用户采用的单幅形象及据此制作的配套多角度稿。
单幅形象为首要外观基准；多角度稿用于镜头参考，新增侧面、背面和未露出的服装结构仍需逐镜复核。

## 成年版本

## 后续使用

生成镜头时实际传入相应参考图，选择最接近目标镜头的角度；特写检查五官，全景检查身形与服装。表情、动作、俯仰角按分镜需要增补。多人同框时另行统一相对身高。
后续修改新建版本，不覆盖已采用图。原始真人照片不在本目录。
