## 小痣与视角规则

- 小痣固定在人物本人左侧，正面时对应画面右侧。
- 位置以当前单幅的眼角、眉尾与太阳穴关系为准，跨年龄按面部比例调整，不能复制整幅画面的绝对坐标。
- 正面和露出本人左眼外侧的四分之三视角可见；画面朝左、展示本人右侧的侧面图中，小痣在远侧被遮挡，不应镜像补到近侧。
- 背面不显示小痣；全身远景的小痣按头部尺寸缩小，不应与头部特写画成相同像素大小。
- 只有一颗圆黑痣，不是双点、短线或成片雀斑。
