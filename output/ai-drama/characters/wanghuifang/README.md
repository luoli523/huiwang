## 特征与依据

正文：山西人，大专毕业，已经工作；高挑、小脸、细眉，皮肤不很白但肤质好，披肩长发，浅米色毛衣与深蓝牛仔裤。温柔随和、单纯，带自然自信和俏皮；重视简单安稳的生活与室友陪伴，后来换到清华校内幼儿园工作。主要依据第 14、21、22、26 章，最初工作单位的章节写法存在差异，不据此设计单位标识。

原型照片 IMG_1139.jpg 由用户提供，原照片未复制到项目；v2 参考其小椭圆脸、细眉眼、自然唇形、高挑修长体态、侧分斜向额发与很长的黑发，发尾自然微卷。最终动画外观以用户已确认的 v2 图片为准。

## 使用约定

多角度稿去掉手持杯子，展示身体和服装结构；单幅未露出的鞋子补为朴素米白低帮帆布鞋，是本次补全设计。具体身高尚未确定，多人镜头另统一相对比例。新增侧面与背面细节仍需逐镜核对，与单幅冲突时优先保持已确认的脸型、五官、发型与气质。

v1 单幅为未参考原型照片的历史初稿，不作为当前镜头参考。后续修订新建版本。
